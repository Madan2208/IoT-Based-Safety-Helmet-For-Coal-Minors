# ⛑️ IoT Based Safety Helmet for Coal Miners

## 📌 Description
The IoT-Based Safety Helmet is a smart wearable system designed to improve the safety of coal miners working in hazardous environments. The helmet integrates sensors and embedded systems to monitor critical environmental parameters such as gas concentration, temperature, and motion in real time.

Mining environments often contain dangerous gases like methane and carbon monoxide, along with extreme temperatures that can pose serious risks to workers. This system continuously collects data using sensors and alerts the user when unsafe conditions are detected, enabling quick preventive action.

---

## ⚙️ Components Used
- Microcontroller (Arduino/NodeMCU)
- Gas Sensor (MQ series)
- Temperature Sensor
- Motion Sensor
- Buzzer / Alert System
- Wireless Module (Wi-Fi / IoT)
- Power Supply

---

## 🚀 Features
- Real-time monitoring of gas levels and temperature  
- Detection of hazardous environmental conditions  
- Instant alerts using buzzer/notifications  
- Lightweight and wearable design  
- Supports remote monitoring using IoT  

---

## 🛠️ Working Principle
The helmet uses sensors to continuously monitor environmental conditions. The collected data is processed by the microcontroller and transmitted through IoT modules to a monitoring system. If any parameter exceeds safe limits, the system triggers an alert to warn the user and prevent accidents.
